# Roadmap

路线图遵循“每一步都可运行、可测试、可比较”的原则。

## v0.1.1 文档生命周期（已完成）

- 删除不再需要的文档
- 删除确认、操作状态和结果数量反馈
- 前端组件测试进入 CI

## v0.1.2 文档编辑（已完成）

- 原位编辑文档标题和正文
- 编辑保存、取消与错误状态反馈
- 清空搜索并恢复完整文档列表

## v0.1.3 标签与筛选（已完成）

- 文档创建和编辑支持多个自由标签
- 关键词与标签组合筛选
- 最新、最早和标题排序
- 点击标签快速筛选

## v0.2.0 Markdown/TXT 文档导入（已完成）

- Markdown、TXT 上传与后端解析器统一接口
- 可编辑预览，保存解析正文与原文件名
- 文件大小、类型、UTF-8 编码和正文长度校验

## v0.2.1 PDF 与分块（待完成）

- PDF 文件上传与解析
- 可配置分块策略与分块预览
- 重复内容校验

## v0.3 向量检索

- 接入 Qdrant
- Embedding 提供商适配层
- 文档分块的增量索引和删除
- Top-K 和相似度阈值配置

## v0.4 可溯源问答

- 使用 Spring AI 构建问答链路
- 流式输出
- 答案引用与原文定位
- 无可靠上下文时拒绝回答

## v0.5 检索质量

- BM25 与向量混合检索
- 查询改写和元数据过滤
- Cross-encoder 重排序
- 检索耗时与命中率观测

## v0.6 产品化

- 用户与知识库权限隔离
- 对话历史、收藏和反馈
- Redis 缓存与限流
- 操作审计

## v0.7 自动评测

- 版本化问答数据集
- Faithfulness、Context Precision、Recall 指标
- 不同分块、模型和检索参数的实验对比
- 回归测试门禁

## v1.0 发布

- Docker 镜像与部署手册
- CI/CD、安全扫描和依赖更新
- 指标、日志与告警
- 示例知识库和演示视频
