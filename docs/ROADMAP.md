# Roadmap

路线图遵循“每一步都可运行、可测试、可比较”的原则。

## v0.2 文档摄取

- Markdown、TXT 和 PDF 文件上传
- 文档解析器统一接口
- 可配置分块策略与分块预览
- 文件大小、类型和重复内容校验

## v0.3 向量检索

- 接入 Qdrant
- Embedding 提供商适配层
- 文档分块的增量索引和删除
- Top-K 和相似度阈值配置

## v0.4 可溯源问答

- 使用 Spring AI 构建问答链路
- 流式输出
- 答案引用与原文定位
- 无可靠上下文时拒绝回答

## v0.5 检索质量

- BM25 与向量混合检索
- 查询改写和元数据过滤
- Cross-encoder 重排序
- 检索耗时与命中率观测

## v0.6 产品化

- 用户与知识库权限隔离
- 对话历史、收藏和反馈
- Redis 缓存与限流
- 操作审计

## v0.7 自动评测

- 版本化问答数据集
- Faithfulness、Context Precision、Recall 指标
- 不同分块、模型和检索参数的实验对比
- 回归测试门禁

## v1.0 发布

- Docker 镜像与部署手册
- CI/CD、安全扫描和依赖更新
- 指标、日志与告警
- 示例知识库和演示视频
