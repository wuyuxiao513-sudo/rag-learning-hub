# Architecture Overview

```text
Vue 3 Web App
      |
      v
Spring Boot REST API
      |
      +---- MySQL/H2       文档元数据、用户和对话
      +---- Redis          缓存、限流和任务状态
      +---- Qdrant         文档分块向量
      +---- Model Adapter  Embedding 与 Chat Model
```

## 设计原则

1. **渐进式复杂度**：v0.1 不依赖外部模型即可运行，后续能力通过明确接口加入。
2. **引用优先**：生成的回答必须保留来源文档、分块和相关度信息。
3. **可替换模型**：业务代码不直接绑定单一模型厂商。
4. **评测驱动**：检索或提示词变更需要通过固定数据集比较效果。
5. **本地优先**：基础开发环境可由 Docker Compose 一键启动。

## 首个架构决策

首版采用关键词检索而非立刻加入大模型。这样能够先验证文档生命周期、API 与用户界面，并为后续向量检索提供清晰基线。
